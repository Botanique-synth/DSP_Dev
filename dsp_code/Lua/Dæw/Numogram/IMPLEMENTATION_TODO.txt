PROJECT OVERVIEW:
-----------------
This is a Faust DSP project building an Elektron-inspired machine that blends:
- Drum synthesis (kick, snare, hats, percussive elements)
- Synth machines (FM, subtractive, granular, wavetable)
- Samplers (for one-shot and looped samples)
- A sophisticated 16-step sequencer with numogram-based parameter mapping

The core concept uses NUMOGRAM DIAGRAM geometry to organize and relate:
- Machine types to numbers (0=clock, 8=drums, 1=synth, 7=sampler, etc.)
- Step positions to harmonic relationships
- Parameter values to numogram ratios

CURRENT STATE (Working):
- Clock system (zero) - Functional BPM and run control
- 16-step sequencer (nine) - Working but needs refactoring
- Drum synthesis (eight) - 4 drum machines: khique, snr, Hate, additive
- Mixer/Effects (one) - 6-channel mixer with delay, reverb, EQ
- Post-processing (postseq) - Routing logic

RESOURCES & REFERENCES:

Faust Documentation:
- https://faust.grame.fr/doc/manual/index.html
- https://faust.grame.fr/doc/libraries/index.html

Elektron Workflow Inspiration:
- Parameter locks: Each step can have unique parameter values
- Pattern chaining: Link patterns together for longer sequences
- Performance macros: Single control affects multiple parameters
- Conditional triggers: Probability, repeats, ratcheting

Numogram Resources:
- Gurdjieff Enneagram: Study the relationships between numbers
- Harmonic series: Use numogram ratios for musical intervals
- Geometric patterns: Visual representation of step relationships

Faust Tips:
- Use par(i, N, expr) for loops
- Use seq(i, N, expr) for sequences
- Use ba.if(cond, then, else) for conditional logic
- Use si.smoo for smoothing parameters
- Use ma.SR for sample rate dependent calculations
- Use de.delay for sample-accurate delays
